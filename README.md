# Bingy 🔔

**By Spooner Labs**

A lightweight Chrome extension that monitors Claude usage and alerts you before limits are reached.

## What it does

- Monitors the Claude usage page (`claude.ai/settings/usage`)
- Tracks session, weekly, and spend usage
- Alerts you via sound and optional notifications before limits are hit

## Getting started

1. Load the extension in Chrome via `chrome://extensions` → **Load unpacked**
2. Navigate to `claude.ai/settings/usage` — Bingy will begin monitoring automatically
3. Configure thresholds and sounds via the popup
